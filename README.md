# 스텔라이브 맛지도 건의함

[스텔라이브 맛지도](https://stfoodmap.sbk-dev.com/)에 실린 내용의 수정·삭제 요청과 새 자료 제보, 사이트 건의를 받는 곳입니다.
맛지도는 스텔라이브 멤버가 방송, 공식 카페, X에서 직접 말한 먹거리를 출처와 함께 모은 **비공식 팬 사이트**이며, 주식회사 스텔라이브와 관계가 없습니다.

## 건의하는 방법

1. 위쪽 **Issues** 탭에서 **New issue**를 누릅니다. (GitHub 계정이 필요합니다.)
2. 알맞은 양식을 고릅니다.
   - **잘못된 내용 수정** — 틀린 메뉴, 틀린 날짜, 끊긴 링크 등
   - **항목 삭제 요청** — 실려 있으면 안 되는 내용
   - **새 자료 제보** — 멤버가 직접 말한 먹거리 가운데 빠진 것
   - **사이트 오류·건의** — 화면이나 지도가 이상할 때, 기능 제안
3. 빈칸을 채워 올립니다.

## 꼭 지켜 주세요

- **이곳에 올린 글은 누구나 볼 수 있습니다.**
- 멤버나 다른 사람의 **사생활(사는 곳, 본명, 연락처, 가족, 건강 등)은 적지 마세요.** 그런 내용이 사이트에 실려 있어 지워 달라는 요청이라면, **어느 항목인지(제목)만** 적어 주세요. 자세한 내용은 적지 않아도 됩니다.
- 새 자료는 **멤버 본인이 직접 말하거나 쓴 것**만 받습니다. 원문을 볼 수 있는 주소(방송 다시보기, 공식 카페 글, X 글)를 함께 적어 주세요. 출처가 없는 이야기, 추측, "집 근처 가게"처럼 사는 곳을 짐작하게 하는 내용은 싣지 않습니다.
- 멤버, 가게, 다른 이용자를 향한 비방은 지웁니다.

## 처리

- 확인한 뒤 사이트에 반영하고 글을 닫습니다. 혼자 운영하는 사이트라 답이 늦을 수 있습니다.
- 사생활이 드러나는 글은 알리지 않고 바로 지울 수 있습니다.
